# Raw Data

This folder contains the unchanged source workbook used by the project.

The full-size synthetic `Logistical_Data.xlsx` is gitignored and distributed
as a [v1.1.0 release asset](https://github.com/Akshith597/logistics-control-tower/releases/download/v1.1.0/Logistical_Data.xlsx).
See [reproduction instructions and SHA256](../../documentation/REPRODUCING.md).

Do not edit the raw workbook. Cleaning and transformation outputs belong in `data/processed`.
